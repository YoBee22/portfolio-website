# Data Driven Systems

Build a modern, recruiter-friendly personal portfolio website for a professional with a background as a Software Engineer transitioning into Data Science. 

DESIGN & AESTHETIC:

- Style: Sleek, high-end tech aesthetic, clean minimalism with subtle dark-mode default or deep slate/navy tones, accented with subtle data-inspired gradients (e.g., electric blue or emerald green). 

- Layout: Asymmetrical grid, generous whitespace, and scannable sections. Avoid looking like a standard static resume document.

SECTIONS REQUIRED:

1. Hero Section: 

   - Headline: A sharp, catchy positioning statement highlighting the dual background (e.g., "Software Engineer turned Data Scientist building intelligent, production-ready systems").

   - Call to Actions (CTAs): Primary button "View Projects" and secondary button "Download Resume". 

   - Social/Profile Links: Clean icon links for GitHub, LinkedIn, and Email.

2. About / Transition Story:

   - A short narrative block explaining how engineering rigor meets data science and machine learning.

3. Featured Projects (Interactive Cards):

   - Include 3 distinct project cards (e.g., RAG/LLM applications, predictive modeling, or data pipelines) featuring a title, tags for tech stack (Python, PyTorch, Airflow, AWS, etc.), a brief description of business impact, and links to GitHub/Live Demo.

4. Technical Expertise / Skills Matrix:

   - Categorized layout: Core Languages (Python, SQL), Data Engineering (PySpark, Kafka, Airflow), Machine Learning/AI (Scikit-Learn, PyTorch, LangChain), and Cloud/Ops (AWS, GCP, Docker).

5. Certifications & Credentials:

   - A clean grid or list layout displaying professional certifications (from LinkedIn, AWS, etc.) with issuing organizations and verification links.

6. Footer: 

   - Minimalist footer with copyright, quick site links, and direct contact invitation.

Make the UI fully responsive, add smooth hover micro-interactions on cards, and ensure high contrast and readability.
